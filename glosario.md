# Glosario Técnico — Monitoreo Ambiental Microbiológico

---

| Término | Definición |
|---|---|
| **UFC** | Unidad Formadora de Colonia. Medida de concentración microbiana viable |
| **Área clasificada** | Zona con control definido de partículas y microorganismos según ISO 14644 |
| **Clase A** | Zona de mayor riesgo: llenado, conexiones críticas. Equivale a ISO 5 |
| **Clase B** | Entorno inmediato de zona A para operaciones asépticas |
| **Clase C / D** | Zonas de menor criticidad para etapas no asépticas |
| **Límite de alerta** | Valor que indica desviación potencial. Requiere investigación |
| **Límite de acción** | Valor que indica pérdida de control. Requiere CAPA inmediata |
| **CAPA** | Acción Correctiva y Acción Preventiva |
| **Rodac** | Replicate Organism Detection And Counting. Placa de contacto estandarizada |
| **Muestreo activo** | Captación de aire con volumen definido mediante impactador |
| **Muestreo pasivo** | Placa de sedimentación expuesta durante tiempo definido |
| **BPM** | Buenas Prácticas de Manufactura |
| **BPL** | Buenas Prácticas de Laboratorio |
| **LIMS** | Laboratory Information Management System |
| **ISO 14644** | Norma internacional para clasificación de salas limpias |
| **Trazabilidad** | Capacidad de reconstruir el historial de un resultado o muestra |
| **QA** | Quality Assurance — Aseguramiento de Calidad |
| **QC** | Quality Control — Control de Calidad |
